# Как обновлять методички

Сайт команды: https://report.jkids-school.ru/

Исходные файлы: https://github.com/Dagar165/jkids-guides

## Обычные правки

1. Открой нужный файл на GitHub и нажми значок карандаша. Тексты методичек находятся в `guides/<название>/index.html`, оформление и общие скрипты — в `assets/`.
2. Сохрани изменение кнопкой **Commit changes** в ветку `main`. Если работаешь через Claude Code или другую нейросеть, попроси её проверить изменения и отправить их в `main`. Изменения в отдельной ветке нужно сначала объединить с `main`.
3. При включённом автодеплое Timeweb сам запустит сборку и обновит сайт. Дождись успешного завершения деплоя, затем обнови страницу.

В панели Timeweb один раз проверь, что включена **«Сборка по последнему выполненному коммиту»**. Без автодеплоя публикацию нужно запускать вручную. Состояние этой настройки пока не проверено.

## Если добавляешь новую методичку

Нужны `guides/<название>/index.html` и `guide.json`. Попроси нейросеть выполнить:

```sh
python3 scripts/build_catalog.py
python3 scripts/build_catalog.py --check
npm run build
```

Новая папка и обновлённый `catalog.json` должны попасть в `main` вместе. Если меняется только текст существующей страницы, каталог пересобирать не нужно. Если меняются название, описание или другие данные карточки — нужно.

## Если изменения не появились

Проверь в Timeweb: ветка `main`, выбран последний коммит, команда сборки `npm run build`, директория сборки `build`, путь до директории проекта пустой. Посмотри статус и лог последнего деплоя. Если сборка успешна, обнови страницу без кеша. При правках CSS/JS нейросеть должна также обновить версии ресурсов в затронутых HTML-файлах.

Папку `build/` вручную не редактируй: Timeweb создаёт её заново. Успешная публикация GitHub Pages не означает, что Timeweb тоже обновился.

## Как откатить

На GitHub остаётся история изменений. Попроси нейросеть отменить конкретный неудачный коммит через `git revert` и отправить исправление в `main`. Для отмены merge-коммита нужно выбрать основного родителя. Не сбрасывай всю ветку к старой версии: так можно потерять более поздние правки.
