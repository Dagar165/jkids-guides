# Методички JKids

Полная методичка по маркетингу: темы, поиск, примеры и рабочие формы.

## Публикация

Settings → Pages → Deploy from a branch → main → / (root) → Save.

Сайт автономный; сборка и внешние библиотеки не нужны.

## Обновление

Новые лекции добавляем в этот же учебный сайт. Факты и примеры сверяем с расшифровкой. Применение к JKids и гипотезы обозначаем отдельно.

Сайт GitHub Pages публичный, доступен всем по ссылке.
