# Учебник команды JKids

Главная: https://dagar165.github.io/jkids-guides/

Один каталог для лекций, мастер-классов и самостоятельных методичек. Каждая карточка ведёт на отдельную страницу. Весь материал по маркетингу сохранён в `guides/marketing/`.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `index.html` | Главная страница |
| `assets/catalog.css`, `assets/catalog.js` | Внешний вид, поиск и фильтры каталога |
| `guides/<slug>/index.html` | Полная методичка, независимая от остальных |
| `guides/<slug>/guide.json` | Название, описание, тип, теги и дата её карточки |
| `catalog.json` | Маленькое оглавление, собранное скриптом |
| `scripts/build_catalog.py` | Сборка и проверка оглавления |
| `AGENTS.md` | Инструкция чату, который добавляет или обновляет материал |

## Добавление материала

Создать папку `guides/<slug>/`, добавить `index.html` и `guide.json` по примеру `templates/guide.json`. Внутри методички нужна ссылка в каталог `href="../../"`. Затем:

```sh
python3 scripts/build_catalog.py
python3 scripts/build_catalog.py --check
```

Опубликовать новую папку и обновлённый `catalog.json` вместе в `main`. Главная сама покажет новую карточку. Для просмотра сайта Python не нужен; он используется только при подготовке обновления.

`added` — дата добавления, не дата лекции. Новые материалы по умолчанию идут первыми. Если нужен отдельный порядок, меньшее значение `order` идёт раньше.

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). Включено автоматическое обновление по коммиту. Настройку не нужно повторять для каждой лекции.

## Почему каталог остаётся лёгким

Главная получает только метаданные. Полные тексты, примеры, таблицы и изображения других методичек не загружаются заранее. Добавление лекции увеличивает каталог на одну карточку, а её содержимое загружается только после перехода.

## Команда для нового чата

> Добавь эту методичку на учебный сайт JKids в репозиторий Dagar165/jkids-guides. Сначала прочитай AGENTS.md и README.md. Создай отдельную папку материала, пересобери каталог, сохрани факты и примеры из расшифровки, проверь и опубликуй. Главную ссылку и остальные методички сохрани.

Сайт и репозиторий публичны. Исходные расшифровки и внутренние решения проекта не публикуются автоматически.
