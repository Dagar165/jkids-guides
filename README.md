# Учебник команды JKids

Основной адрес для команды: https://report.jkids-school.ru/

Дополнительный адрес GitHub Pages: https://dagar165.github.io/jkids-guides/

Короткая инструкция по правкам и автообновлению: [UPDATE.md](UPDATE.md).

Один каталог методичек, основанных на фактах предоставленных лекций. Каждая карточка ведёт на отдельную страницу. Весь материал по маркетингу сохранён в `guides/marketing/`.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `index.html` | Главная страница |
| `assets/catalog.css`, `assets/catalog.js` | Внешний вид, поиск каталога |
| `guides/<slug>/index.html` | Полная методичка, независимая от остальных |
| `guides/<slug>/guide.json` | Название, описание, проверяемые действия, теги и дата карточки |
| `catalog.json` | Маленькое оглавление, собранное скриптом |
| `scripts/build_catalog.py` | Сборка и проверка оглавления |
| `METHOD.md` | Стандарт обучения: база, решения с рассуждением, практика и обратная связь |
| `guides/marketing/source-content.json` | Полное прежнее содержание, включая таблицы и оговорки |
| `guides/marketing/learning.json` | Учебные цели, объяснения, задачи, разборы и заполненные образцы |
| `AGENTS.md` | Инструкция чату, который добавляет или обновляет материал |

## Добавление материала

Создать папку `guides/<slug>/`, добавить `index.html` и `guide.json` по примеру `templates/guide.json`. Внутри методички нужна ссылка в каталог `href="../../"`. Затем:

```sh
python3 scripts/build_catalog.py
python3 scripts/build_catalog.py --check
```

Опубликовать новую папку и обновлённый `catalog.json` вместе в `main`. Главная сама покажет новую карточку. Не добавлять категории «лекции» и «мастер-классы»: это виды исходников, а не разные продукты обучения. Для просмотра сайта Python не нужен; он используется только при подготовке обновления.

`added` — дата добавления, не дата лекции. Новые материалы по умолчанию идут первыми. Если нужен отдельный порядок, меньшее значение `order` идёт раньше.

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). Включено автоматическое обновление по коммиту. Настройку не нужно повторять для каждой методички.

## Публикация на Timeweb Cloud

Сайт состоит из готовых HTML/CSS/JS-файлов, React и внешние npm-зависимости ему не нужны. Для существующего приложения Timeweb, которое запускает `npm run build`, добавлена упаковка сайта на Node.js 22 или новее:

```sh
npm ci
npm run build
```

Настройки frontend-приложения: ветка `main`, директория проекта — корень репозитория (поле оставить пустым), команда сборки `npm run build`, директория сборки `build`. Отдельная команда запуска и SSR не нужны.

17 октября 2026 Сергей подтвердил, что сайт на поддомене работает после исправления сборки. Автообновление требует включённого автодеплоя в Timeweb («Сборка по последнему выполненному коммиту»); состояние этой настройки в панели не проверялось. При включённом автодеплое каждый новый коммит в `main` запускает сборку и публикацию. Правки в других ветках появятся на сайте после их объединения с `main`.

Команда копирует `index.html`, `catalog.json`, `assets/`, `guides/` и `.nojekyll` в `build/` без изменения содержимого. Python на сервере не нужен: каталог по-прежнему обновляется перед коммитом командой `python3 scripts/build_catalog.py`. Папка `build/` в Git не хранится; инструкции, скрипты и файлы npm в неё не попадают. GitHub Pages продолжает читать исходные файлы из корня.

При создании нового приложения можно выбрать тип HTML/CSS/JS и публиковать готовый сайт из корня без сборки. Инструкция Timeweb: https://timeweb.cloud/docs/apps/deploying-frontend-apps/static-website

Перед исправлением деплоя сохранена ветка `backup/before-timeweb-fix-2026-10-17` на коммите `6e892f65ea42c0ba2eb7e8e93acdf51771d5559c`. Для возврата к исходной версии используй `git revert` коммита исправления; не делай принудительный сброс `main`, чтобы не потерять последующие обновления методичек.

## Почему каталог остаётся лёгким

Главная получает только метаданные. Полные тексты, примеры, таблицы и изображения других методичек не загружаются заранее. Добавление методички увеличивает каталог на одну карточку, а её содержимое загружается только после перехода.

## Редакция маркетинга

Каждый из 18 учебных разделов содержит конкретное действие, объяснение его смысла, базовые понятия, полный прежний разбор, модель решения, задачу с обратной связью и перенос в работу. Два служебных раздела сохраняют правила чтения и карту источников. Придуманные ситуации подписаны; возможности и результаты JKids из них не выводятся.

Ответы в полях сохраняются только локально в браузере. Для проверки их нужно скопировать и передать коллеге привычным способом. Сервер не собирает ответы. Освоение проверяется по самостоятельной работе и исправлению после замечаний, а не по открытым карточкам.
